Note

The Note card draws a caption box over the chart — a base, a source, a reading key, a warning. Its text is not just static: it can compute values from the fields already placed in the visual, and it can switch to an alert wording when a threshold is crossed.

Available everywhere

The card is exposed by the Column Chart, Scatter Plot, Gradient Heatmap, Radar and Pie Chart. The Line Chart keeps its own, simpler Cartouche card for now.

Text and formulas​

The Text property accepts free text mixed with formulas over any field placed in the visual — the field name is the one shown in the field well:

FormulaResult
%MIN(field)Smallest value of the field
%MAX(field)Largest value of the field
%COUNT(field)Number of values
%AVG(field)Mean of the values
%SUM(field)Sum of the values
Base : %MIN(base_rep) to %MAX(base_rep) respondents

A field name that matches nothing renders as #NAME?, and a formula with no usable value renders as #N/A — both are visible on the chart rather than silent, so a typo is caught immediately.

Display Units and Decimals control how those computed numbers are written.

Position​

PropertyDescriptionDefault
PositionTop or Bottom, each in Left / Center / RightTop (Left)
Horizontal marginDistance from the left or right edge8
Vertical marginDistance from the top or bottom edge8
PaddingSpace between the border and the text6

The Note is not painted over the chart: the band it occupies is reserved, and the plot — along with the legend — is pushed out of its way. When a horizontal legend sits in the same band, the two share the line if they are in different zones; otherwise the whole Note box is reserved on top of the legend, and the legend stays the closer of the two to the chart.

Alert​

The alert swaps the appearance of the Note as soon as a condition is met — typically a base falling under a publication threshold.

PropertyDescription
AlertMaster toggle of the alert block
Test ifLeft operand: a number, or a formula such as %MIN(base_rep)
IsComparison operator: <, = or >
ToRight operand
Alert textReplaces the Note text while the alert holds. Leave empty to keep the normal text. Formulas are accepted here too.
PrefixPlaced before the text while the alert holds — usually a pictogram such as ⚠️
Text / Background / Border ColorColors used while the alert holds

Because Test if accepts a formula, the alert reacts to the data actually plotted rather than to a fixed value:

Test if  %MIN(base_rep)   Is  <   To  50
Alert text  ⚠️ Base too small — results are indicative only

Relationship with the Global Threshold​

The two cards answer different questions and can be used together:

Global ThresholdNote
What it doesErases the chart and paints a message in its placeAdds a caption next to a chart that is still drawn
When to use itThe result must not be published at allThe result is publishable but needs a caveat

A common pairing is an alert Note under a moderate base, and the Global Threshold under a base too small to show anything.
