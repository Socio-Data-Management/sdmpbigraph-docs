Legend

The Legend card identifies each category with a color indicator (or logo) and name.

Properties​

PropertyDescriptionDefault
ShowShow/hide legendOn
Vertical PositionTop, Center, BottomTop
Horizontal PositionLeft, Center, RightRight
Legend DisplayText, Logo and Text, LogoText
Logo Width/HeightLogo dimensions (px)20
Logo display

Logo and Logo and Text display modes require a Logo data role. The legend reuses the same per-series logos as the markers.
