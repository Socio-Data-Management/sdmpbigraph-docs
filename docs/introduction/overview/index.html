SDM Smart Graph Visuals

The SDM Smart Graph Visuals suite provides six professional-grade chart visuals for Power BI:

  • Smart Column Chart — Grouped and stacked column/bar charts
  • Smart Line Chart — Multi-series line charts with end-of-line labels
  • Smart Scatter Plot — XY scatter plots with size encoding and zoom insets
  • Gradient Heatmap — Continuous heat surfaces interpolated from scattered sample points
  • Smart Radar — Spider webs over n axes, each carrying its own scale
  • Smart Pie Chart — Pies, donuts and half-circle gauges, as small multiples or concentric rings

Key Features​

All six visuals share a common foundation — the About dialog, the Global Threshold panel, the licensing card, native tooltips and cross-filtering. Beyond that, each visual carries the features that make sense for its own shape:
