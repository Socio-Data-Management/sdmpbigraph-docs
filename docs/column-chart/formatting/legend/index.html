Legend

The legend identifies each series with a color indicator and name.

Properties​

PropertyDescriptionDefault
ShowShow/hide the legendOn
PositionTop, Bottom, Left, RightTop
FontFont family, size, bold, italic, underlineSegoe UI, 11px
Match Series ColorColor legend text to match its seriesOff
Legend DisplayText, Logo and Text, LogoText
Logo WidthWidth of logo images in the legend (px)20
Logo HeightHeight of logo images in the legend (px)20

Legend Display Modes​

When a Series Logo is provided:

  • Text — Traditional display: color square + series name
  • Logo and Text — Logo image + series name (no color square)
  • Logo — Logo image only (no text)

If a series has no logo, it falls back to Text mode regardless of the setting.

Logo Width/Height

The Logo Width and Logo Height properties only appear when Legend Display is set to "Logo and Text" or "Logo".
