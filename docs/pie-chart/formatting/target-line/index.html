Target Line

A radial mark drawn at the angle carrying a target value — the visual equivalent of a goal line on a bar chart, and what turns a half donut into a gauge.

PropertyDescriptionDefault
Show target lineMaster toggleOff
Target valueThe value to mark(empty)
Target unitValue or Percentage of totalValue
ExtentRing only or Full radiusRing only
ColorLine color#C62828
Width (px)Line thickness3
StyleSolid, dashed or dottedSolid
Overhang (px)How far the line sticks out past each end3

Target unit​

SettingThe angle is computed as
Valuetarget / total of the series — the target is expressed in the units of the measure
Percentage of totaltarget / 100 — the target is a share, from 0 to 100

Targets outside the range are clamped to the ends of the chart rather than wrapping around.

One target per series​

Target value carries the fx button. A rule bound to the legend field gives each series its own target, which is what makes a grid of small multiples or a stack of concentric rings comparable against their individual goals. The value typed in the card is used for any series the rule leaves empty.

Extent​

SettingThe line runs
Ring onlyFrom the inner to the outer edge of each ring, so every ring shows its own target
Full radiusFrom the centre to the outer edge, one line across the whole chart

Ring only is meaningful on a donut; on a full pie the ring already reaches the centre and the setting is hidden.
