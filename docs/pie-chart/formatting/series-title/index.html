Series Title

The caption identifying each small multiple. The card applies to the Small multiples layout only — concentric rings share one chart area and are identified by the legend instead.

PropertyDescriptionDefault
Show Series TitlesMaster toggleOn
PositionTop or Bottom of each chartTop
FontFamily, size, bold, italic, underlineSegoe UI 11, bold
Text ColorFixed color of the caption#333333
Assign series color to font colorPaints the caption with the series color insteadOff

Series logos lookup​

The list maps an exact series name to a base64 image:

[
  { "label": "France",  "logo": "data:image/png;base64,iVBORw0KG..." },
  { "label": "Germany", "logo": "data:image/png;base64,iVBORw0KG..." }
]

Two ways to fill it:

  • The picture icon on the visual (edit mode, small multiples with several series) opens an editor pre-filled with one row per series — paste a base64 image next to each name.
  • The fx button binds a DAX measure that builds the whole list, which is the better option when the images already live in a lookup table:
Series Logos JSON =
"[" &
CONCATENATEX (
    VALUES ( Markets[market_name] ),
    "{""label"":""" & Markets[market_name] & """,""logo"":""" & MAX ( Markets[flag_base64] ) & """}",
    ","
) & "]"

A label that matches no series is ignored, a duplicate label keeps its first entry, and malformed JSON simply yields no logo — the lookup never breaks a render. Entries go through the same base64 validation as every other image field: external URLs are rejected.

The lookup wins over the Logo role for the titles, so a per-category logo can paint the slices and the legend while the lookup paints the titles.

Logos​

Logo and Text and Logo need the Logo field well to return a base64-encoded image for the legend value — a flag for a chart per country, a brand mark for a chart per brand.

Use the Series logos lookup

A title logo identifies the legend value, which the Logo role cannot name: a column dropped there joins the category axis, and a measure costs one evaluation per cell. Use the Series logos (JSON) field below instead — resolved once per render, and it keeps the two sets of images apart.

When no image is available for a series, that title falls back to plain text rather than leaving a hole in the grid.

Titles longer than the chart cell are truncated with an ellipsis, measured against the real font, so a long series name never overlaps its neighbour.
