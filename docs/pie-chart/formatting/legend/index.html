Legend

The legend lists whichever dimension carries the colors: the categories by default, or the series when the Pie card has Apply colors to set to Series. It is hidden automatically when there is only one item to name.

PropertyDescriptionDefault
Show LegendMaster toggleOn
PositionTop, Bottom, or Left / Right in three vertical alignmentsBottom
FontFamily, size, bold, italic, underlineSegoe UI 11
Assign item color to font colorPaints each label with its own colorOff
Legend DisplayText, Logo and Text, or LogoText
Text WrapEllipsis (one line, ends with …) or Wrap (flows onto several lines). Never scrolls.Ellipsis
Logo Width / HeightSize of the logos, in pixels20 × 20

Positions​

Top and Bottom lay the legend out horizontally across the full width, centred. The four side positions stack the entries vertically in a column capped at 150 px wide, aligned to the top, the middle or the bottom of the plot area. The chart takes whatever space is left.

Logos​

Logo and Text and Logo need the Logo field well to return a base64-encoded image. On a pie the field is read per category for the legend, and per legend value for the series titles — the same field feeds both, on two different dimensions.

Entries without an image fall back to text, so a partially filled Logo field still produces a readable legend.

Text Wrap​

A legend box is bounded: 150 px wide when it sits on the left or the right, the width of the visual when it sits on top or below. Text Wrap decides what happens to an entry that does not fit.

ModeResult
Ellipsis (default)The entry stays on one line and ends with an ellipsis
WrapThe entry flows onto as many lines as it needs

Neither mode ever produces a scrollbar. A scrollbar inside a report tile hides entries behind a control nobody thinks to drag, so it was removed outright.

Entries that no longer fit

With scrolling gone, a legend taller than the space it has is clipped rather than scrolled. Wrap makes entries taller and so clips sooner than Ellipsis — give the legend a horizontal position, or shorten the labels, when every series has to stay visible.
