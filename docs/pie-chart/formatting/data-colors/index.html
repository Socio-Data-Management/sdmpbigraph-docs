Data Colors

The card lists one color picker per category — or per series when the Pie card has Apply colors to set to Series. The list follows the switch, so exactly one dimension is colored at a time.

PropertyDescription
Default ColorFallback used before any per-item color is resolved
One picker per itemThe resolved color of that category or series

Every picker carries the fx button, so a color can be computed by a conditional formatting rule instead of being picked by hand.

Resolution order​

For each slice, the first source that returns a color wins:

  1. Conditional formatting (fx) set on the item in this card
  2. The Series Color field well, read on the dimension chosen by Apply colors to
  3. The report theme palette
  4. The built-in SDM fallback palette

Series Color field​

The field expects a hex code such as #FF0000, returned by a measure or a column. Feeding colors from the model is the practical way to keep a category the same color across every report page, and to drive colors from a lookup table rather than from the visual.

Because the field is read on one dimension only, switching Apply colors to re-reads the same field on the other dimension — there is no second field to fill in.

A column works when the color is an attribute of the category, which is the usual case: a brand color next to a brand name. A color that identifies the legend value has to be a measure — see Column or measure?.
