Highlight

Pulls one or more slices out of the crowd, selected by a regular expression rather than by hand — so the emphasis follows the data instead of a position on screen.

PropertyDescriptionDefault
Highlight slicesMaster toggleOff
Pattern (regex)Case-insensitive regular expression(empty)
Match onCategories or SeriesCategories
Match statusRead-only: how many slices matched, or why none did—
Highlight modeSee belowExplode

The pattern carries the fx button, so a measure or a rule can compute which slices to emphasise — for example the top performer of the current filter context.

Highlight modes​

ModeEffectRelated settings
ExplodeThe matching slices slide outward along their own bisectorExplode Offset (px)
OutlineThe matching slices get a thicker, colored borderOutline Color, Outline Width
Dim the othersEvery non-matching slice drops to a lower opacityOpacity of the others
Explode + outlineBoth of the first twoAll of the above

Only the settings that apply to the selected mode are shown in the pane.

Matching​

  • Categories matches the category label of each slice, so the same slice is emphasised on every chart — useful to follow one product across a grid of small multiples.
  • Series matches the legend value, so a whole chart or a whole ring is emphasised.

The regex is case-insensitive. Other|Misc matches either word; ^Total$ matches the exact label. An invalid expression is reported in Match status and no slice is emphasised.

Interaction with cross-filtering​

Clicking a slice cross-filters the report and dims the slices outside the selection. While a selection is active it owns the opacity of the chart; Dim the others takes over again as soon as the selection is cleared. Explode and outline are unaffected by selection.
