Scale

The Scale card decides how values are mapped onto the radius of each axis. This is what lets a score out of 50 and a score out of 10 sit on the same web without one crushing the other.

Scale Mode​

PropertyDescriptionDefault
Scale ModePer axis gives every axis its own range, taken from the values observed on that axis alone. Shared gives every axis the same range, the union of all observed values.Per axis
Graduations depend on this

The Web and Circles graduation styles join equal radii across axes, which only means something when every axis shares one scale. With Per axis they fall back to Ticks — see Graduations.

Range​

PropertyDescriptionDefault
Start at ZeroPull the minimum of each axis down to zero (or to the data minimum if it is negative)Off
Range PaddingWiden the range by this percentage so vertices do not sit exactly on the outer ring. When Start at Zero is on, only the top is pushed out — zero stays pinned.5 %
Inner RadiusHollow out the centre of the web, as a percentage of the outer radius. The axis minimum then sits on that inner ring.0 %

Values falling outside the resolved range are clamped, so a thread never escapes the web.

Manual bounds per axis​

In edit mode, a gear icon appears in the top-right corner of the visual. It opens a dialog with one row per axis and a Minimum / Maximum field on each.

The fields are pre-filled with the bounds currently in use, so confirming the dialog pins every axis at once. Bounds are stored as JSON on the visual and survive refreshes; clearing a value returns that axis to automatic scaling.

When to pin bounds

Pin the bounds when the axes are rating scales with a known ceiling — a score out of 10 should be plotted against 0..10, not against the range the current filter happens to produce.
