Add. Table

The Add. Table adds rows of values to the chart — one cell per category, centred on its point: a base, a mean coming from another measure, a score, a logo. It is the same feature as in the Column Chart, laid out as rows.

Filling the well​

Drop one or more measures in the Add. Table data role. Each measure becomes one row. The measures are not drawn as lines; with a Legend, each measure is read once per category (the legend values are merged).

The column editor​

In Edit mode, hover over the visual and click the ⚙ icon (top right, next to the ⓘ icon). The editor opens with one entry per measure of the well: format (font, size, colour, style, header, row height), row box (border, background, shadow), logo, separator, warning thresholds (low / high, marker, value colour, pill) and critical threshold. It is the column chart's editor — see The column editor for every setting. The result is stored as JSON in the Add. Table card of the Format pane.

Above or under the chart​

The Position of each row decides where it goes:

PositionWhere the row is drawn
After the chart (default)Under the X axis labels, and under the Base Row when it is shown
Before the chartAbove the plot area

The row names are written in the left margin, left-aligned like the base row label, and truncated so they never cross the Y axis. The margin widens to hold them, up to a third of the visual.

Thresholds​

Alert and critical thresholds work as in the Column Chart. On a line chart, a category blanked by a critical threshold:

  • is left as a gap in every line — the missing values mode decides whether the line breaks or bridges it;
  • shows no value in the Add. Table rows nor in the base row;
  • shows the replacement message, if any, over the plot area at its place;
  • keeps its label on the X axis.

A blanked category still serves as a reference for the significance tests: vs. Preceding category compares with it even though it is hidden.
